# 🌌 Celestial Love Journey - Mobile App

An intimate, poetic mobile application designed with **Futuristic Etherealism** and **Delicate Glassmorphism**, built under deep space voids and lunar regolith tones.

---

## ✨ Features

- **Chapter 01: The First Glimpse**
  - Atmospheric celestial hill silhouette with handholding lovers gazing at the starlit horizon.
  - Realistic luminous crescent moon with crater rim texture, earthshine disk, and atmospheric halo.
  - Poetic verse with smooth scroll indicator.
- **Chapter 02: Our Gravitational Field**
  - **Interactive 3D Moon Sphere**: Drag, flick, or touch-rotate the moon with momentum inertia and passive orbit.
  - **7 Constellation Memory Beacons**:
    1. *California burrito* (1046.50 Hz - C6)
    2. *Polar bear* (1318.51 Hz - E6)
    3. *Naturals* (1567.98 Hz - G6)
    4. *Dumbass* (1975.53 Hz - B6)
    5. *Hrithik Roshan* (2093.00 Hz - C7)
    6. *YRC* (2349.32 Hz - D7)
    7. *BGS* (2637.02 Hz - E7)
  - **Cosmic Synthesizer Engine**: Web Audio API real-time synthesis reproducing crystal glass strikes, resonant overtones, and harmonic delay reverb.
  - **Glassmorphic Memory Card**: Displays the chosen memory beacon, starlight resonance frequency, and haptic feedback.
- **Chapter 03: The Eternal Acceptance**
  - Sacred triple acceptance typographic climax.
  - **Return to the Beginning ∞**: Smooth return animation loop.
- **Secret Stardust Vault**:
  - Slide-up bottom drawer with romantic letter, accessible via the top lock icon.
  - Swipe down gesture or backdrop tap to dismiss.
- **Cosmic Lo-Fi Ambience**:
  - Synthesized ambient binaural drone (A2 110Hz + 164.81Hz chord tone) toggleable from the top control pill.
- **PWA Ready**:
  - Web App Manifest (`manifest.json`) and Service Worker (`service-worker.js`) for "Add to Home Screen" on iOS & Android.
- **Desktop Device Mode**:
  - Sleek phone preview frame on desktop with one-click viewport expander.

## 🚀 Running Locally

To start the local development server:

```bash
npm start
```
or
```bash
node server.js
```

Then open your browser at:
👉 **[http://localhost:3000](http://localhost:3000)**

### 📱 Testing as a Mobile App:
1. Open the URL in Google Chrome, Edge, or Safari.
2. Press `F12` (or `Ctrl+Shift+I` / `Cmd+Option+I`) to open Developer Tools.
3. Click the **Toggle Device Toolbar** icon (or press `Ctrl+Shift+M` / `Cmd+Shift+M`).
4. Select a device like **iPhone 14 Pro**, **Pixel 7**, or **Galaxy S20** to experience full mobile touch gestures, haptics, and responsive layout.
