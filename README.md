# 🌌 Celestial Love Journey

An intimate mobile web app experience inspired by **[igloo.inc](https://www.igloo.inc/)** with 3D crystal lunar physics, crystalline Web Audio chime synthesizer, and memory constellation beacons.

---

## ✨ Highlights

- **igloo.inc Style 3D Interactive Moon**:
  - Photorealistic lunar sphere with dynamic specular light glint following mouse/device tilt.
  - Inertial flick-spin momentum and passive orbital rotation.
  - Orbital radar guide rings with coordinate markings (`00°N`, `180°S`, `270°W`, `090°E`).
- **7 Frosted Crystal Memory Beacons**:
  1. `01` **California burrito**
  2. `02` **Hrithik Roshan**
  3. `03` **Polar bear**
  4. `04` **Dumbass**
  5. `05` **YRC**
  6. `06` **Naturals**
  7. `07` **BGS**
- **Web Audio API Sound Engine**: Real-time synthesized crystalline bells and binaural cosmic lo-fi drone.
- **Buttery Smooth Scroll**: Native smooth kinetic scrolling with scroll-driven reveals and chapter breadcrumbs.
- **Infinite Cosmic Loop**: Seamless warp loop when scrolling past the bottom.
- **Customizable Memories**: Onboard modal editor that saves your sentences to `localStorage`.

## ⚡ Deploying to Vercel (1-Click)

This project is fully optimized for static hosting on **Vercel** with zero build configuration needed.

### Option 1: Via Vercel Dashboard (Easiest)
1. Push this repository to your GitHub:
   ```bash
   git push -u origin main
   ```
2. Go to **[vercel.com/new](https://vercel.com/new)**.
3. Import your repository (`MyP`).
4. Click **Deploy**! Vercel will instantly publish it to a global Edge CDN URL (e.g. `https://myp-xyz.vercel.app`).

### Option 2: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
